## Описание возможностей

Приложение PlaylistMaker позволяет осуществлять:
- поиск музыкальных композиций по базе iTunes
- сохранять историю поиска
- прослушивать отрывки найденных аудиотреков
- добавлять аудиотреки в общий пул избранного
- формировать и редактировать плейлисты

## Техноческое описание

При создании проекта использовались:
- Android SDK
- Язык программирования - Kotlin
- Подход Single Activity с архитектурным шаблоном MVVM
- Работа с сетевыми запросами через Retrofit
- Для работы с базой данных используется библиотека Room
- Навигация реализована через Jetpack Navigation Component
- Внедрение зависимостей осуществляет Koin
- Асинхронные задачи с реализацией на Coroutines
